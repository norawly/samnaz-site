# Размещение сайта: samnaz.group — основной, samnaz.kz — перенаправление

Схема, в которой не платится ни тенге сверх уже оплаченных доменов.

| Что | Где | Цена |
|---|---|---|
| Код | GitHub, приватный репозиторий | 0 ₸ |
| **samnaz.group** — сам сайт | Cloudflare Pages | 0 ₸ |
| **samnaz.kz** — редирект на .group | DNS-хостинг hoster.kz | 0 ₸ |
| Заявки | Telegram напрямую из браузера | 0 ₸ |

Бэкенда нет вообще: сайт статический, форма стучится в Telegram из браузера
посетителя. Держать нечего — значит и платить не за что.

## Шаг 1. Репозиторий на GitHub

Git уже настроен, коммиты сделаны. Осталось создать удалённый репозиторий и залить.

1. Аккаунт на <https://github.com>, если его ещё нет.
2. **New repository** → имя `samnaz-site` → **Private** → README/gitignore
   **не** добавлять → Create repository.
3. В терминале, в папке проекта:

```bash
git remote add origin https://github.com/ТВОЙ_ЛОГИН/samnaz-site.git && git push -u origin main
```

Пароль от GitHub при пуше не подойдёт — нужен токен. Settings → Developer
settings → Personal access tokens → **Tokens (classic)** → Generate new token →
галочка `repo` → Expiration: **No expiration** → скопировать и вставить
вместо пароля.

Проще один раз поставить GitHub CLI и не думать про токены:

```bash
gh auth login && gh repo create samnaz-site --private --source=. --push
```

## Шаг 2. samnaz.group на Cloudflare Pages

### Деплой

1. Регистрация на <https://dash.cloudflare.com> — бесплатно, карта не нужна.
2. **Workers & Pages** → Create → вкладка **Pages** → Connect to Git →
   подключить GitHub, выдать доступ к `samnaz-site`.
3. Настройки сборки (сайт без сборщика, поэтому всё пустое):
   * Framework preset — **None**
   * Build command — **пусто**
   * Build output directory — **`/`**
4. Save and Deploy. Через минуту сайт живёт на `samnaz-site.pages.dev`.

### Домен

1. В Cloudflare: **Add a site** → `samnaz.group` → план **Free**.
2. Cloudflare выдаст два своих NS вида `xxx.ns.cloudflare.com`.
3. Namecheap → Domain List → Manage → Nameservers → **Custom DNS** →
   вставить оба → сохранить. Перестройка: от 20 минут до суток.
4. Pages → проект → **Custom domains** → Set up a domain →
   добавить `samnaz.group`, затем отдельно `www.samnaz.group`.

HTTPS Cloudflare выпустит и будет продлевать сам, бесплатно и бессрочно.

## Шаг 3. samnaz.kz → редирект на samnaz.group

Тут есть тонкость, из-за которой нельзя просто повесить .kz на Cloudflare.

**Правила зоны `.kz` требуют казахстанский IP.** Если A-запись `samnaz.kz`
смотрит на иностранный сервер (а Cloudflare — иностранный), приходит
предупреждение, даётся 10 дней, потом домен приостанавливают, ещё 10 дней —
удаляют из реестра. Оплата на 10 лет вперёд от этого не спасает.

Решение бесплатное и полностью законное: редирект делает **сам hoster.kz**
на своём казахстанском сервере. Домен смотрит на IP в Казахстане — правила
соблюдены; посетитель мгновенно улетает на `samnaz.group` — как ты и хотел.

### Настройка

1. Личный кабинет hoster.kz → **Домены** → `samnaz.kz`.
2. Убедиться, что стоят их NS: `ns1.hoster.kz`, `ns2.hoster.kz`, `ns3.hoster.kz`.
   Без этого редирект не заработает.
3. Включить переключатель **DNS-хостинг**, если он выключен.
4. Проверить A-записи — и `samnaz.kz`, и `www.samnaz.kz` должны указывать
   на **`89.35.125.9`** (это редирект-сервер hoster.kz).
5. Включить опцию **«Редирект на домене»**:
   * тип — **301** (постоянный: браузеры запоминают, поисковики склеивают
     вес доменов и не считают это дублем);
   * целевой URL — `https://samnaz.group`.
6. Сохранить. Проверить через 10–20 минут: `samnaz.kz` должен сам открывать
   `samnaz.group`.

### Обязательно проверь HTTPS

Открой именно **`https://samnaz.kz`** (не `http://`). Возможны два исхода:

* **Открылось и перебросило** — всё, готово, дальше ничего не делай.
* **Ошибка сертификата** — значит на редирект-сервере нет SSL для твоего
  домена. Напиши в поддержку hoster.kz: *«Прошу выпустить бесплатный
  Let's Encrypt на домен samnaz.kz, используется ваш сервис редиректа»*.
  Обычно включают бесплатно. Если откажут — берёшь самый дешёвый тариф
  Economy-1 (~500 ₸/мес), там Let's Encrypt точно есть, и делаешь редирект
  уже на нём. Это единственное место во всей схеме, где теоретически могут
  появиться расходы.

Без рабочего HTTPS домен тоже могут заблокировать — это отдельный пункт
правил зоны, поэтому пункт не пропускай.

### Проверка на соответствие правилам

<https://rules.hoster.kz/?domain=samnaz.kz>

Должно быть зелено: казахстанский IP, живой SSL, корректный WHOIS.

## Что происходит с SEO

`samnaz.group` объявлен основным: во всех страницах прописан
`<link rel="canonical" href="https://samnaz.group/...">`, `sitemap.xml`
и `robots.txt` тоже ссылаются на `.group`. Редирект 301 с `.kz` передаёт
туда накопленный вес. Поисковики поймут схему правильно.

Когда сайт заработает — добавь `samnaz.group` в Google Search Console
и Яндекс.Вебмастер, скорми им `https://samnaz.group/sitemap.xml`.

## Что нужно продлевать

Оба домена оплачены на 10 лет — это, собственно, всё. Cloudflare Pages,
GitHub, SSL-сертификаты продлеваются автоматически и бесплатно.

Одна просьба: включи **автопродление** на обоих доменах (hoster.kz и
Namecheap) и держи на привязанной карте живой баланс. Сайты почти никогда
не умирают от поломок — они умирают от забытого продления домена.

## Как вносить изменения

```bash
git add -A && git commit -m "что поменял" && git push
```

Через ~60 секунд обновилось на `samnaz.group`. Никакого FTP.

Полезное:
* Откат к любой прошлой версии: Cloudflare Pages → Deployments → Rollback.
* Черновик: пуш в ветку `test` — Cloudflare сделает отдельную превью-ссылку,
  основной сайт не тронется.
* Лимиты Free-тарифа: 500 сборок в месяц (~16 правок в день), трафик
  не ограничен, 20 000 файлов, файл до 25 МБ. Наш сайт — 184 файла и 70 МБ.

## Про токен Телеграм-бота

Токен лежит в `assets/js/vendor/metrics.js` внутри сайта — так ты просил,
чтобы всё работало без сервера. Важно понимать: **приватный репозиторий его
не прячет.** Файл отдаётся вместе со страницей любому посетителю, base64
разворачивается за секунду.

Пока сайт малоизвестен — риск невелик. Если однажды токен утащат, чужой
человек сможет писать от имени бота и читать заявки. Лечится в любой момент:
в папке `bot/` лежит готовый Cloudflare Worker — бесплатно, 10 минут,
токен уезжает в серверный секрет, в сайте остаётся только адрес эндпоинта.
Подробности — в `ТЕЛЕГРАМ-БОТ.md`.
