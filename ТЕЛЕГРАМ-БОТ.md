## О чём надо знать

Вы просили положить ключ прямо в сайт — так и сделано. Но я обязан назвать вещи своими именами, чтобы это не стало сюрпризом.

**Ключ виден любому посетителю.** Он лежит в файле, который браузер скачивает вместе со страницей. Имя файла невзрачное, строка закодирована — это мешает автоматическим сканерам, но не человеку: достаточно открыть инструменты разработчика и посмотреть исходящий запрос. Считайте, что ключ публичный.

**Что сможет сделать посторонний, если возьмёт ключ:**

* читать все заявки, которые приходят боту, — это телефоны и имена ваших клиентов;
* писать сообщения от имени бота всем, кто ему писал;
* рассылать спам — за это Telegram блокирует бота.

**Зачем кодировка.** GitHub автоматически ищет в репозиториях токены Telegram. Найдя такой в открытом виде, он сообщает Telegram, и тот отзывает токен — бот молча перестаёт работать. В закодированном виде этого не произойдёт.

**Чего в этом режиме нет.** Команда `/start` с логином и паролем не работает: чтобы отвечать на сообщения, нужен постоянно работающий обработчик, а на статическом сайте его нет. Сейчас заявки просто уходят в указанные чаты.

**Если сайт пойдёт в рост** — переключение на безопасный режим занимает минут пятнадцать, всё уже написано (ниже). Тогда ключ уедет на сторону обработчика, а вместе с ним заработают `/start`, логин с паролем и подписка сотрудников.

# Безопасный режим (когда понадобится)

## Что нужно сделать один раз

### 1. Создать бота

В Telegram напишите **@BotFather** → `/newbot` → задайте имя.
В ответ придёт токен вида `123456789:AAE...` — он понадобится дальше.

### 2. Завести бесплатный аккаунт Cloudflare

<https://dash.cloudflare.com/sign-up> — карта не нужна.

Затем в терминале:

```bash
npm install -g wrangler && wrangler login
```

### 3. Создать хранилище

Оно держит список подписанных сотрудников и защиту от спама.

```bash
cd "/Users/nuralizhengisbay/Documents/Projects/Sam Naz Eng/bot" && wrangler kv namespace create SAMNAZ
```

Команда вернёт `id = "..."` — впишите его в `bot/wrangler.toml` вместо `ВСТАВЬТЕ_ID_ПОСЛЕ_СОЗДАНИЯ`.

### 4. Задать секреты

Каждая команда спросит значение — вставляете и жмёте Enter.

```bash
cd "/Users/nuralizhengisbay/Documents/Projects/Sam Naz Eng/bot" && wrangler secret put BOT_TOKEN
```

Дальше так же: `wrangler secret put BOT_LOGIN`, `wrangler secret put BOT_PASSWORD`,
`wrangler secret put WEBHOOK_SECRET`.

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `BOT_LOGIN` | логин, который бот спросит после `/start` |
| `BOT_PASSWORD` | пароль к нему |
| `WEBHOOK_SECRET` | случайная строка, чтобы боту не слали фальшивые события |

Случайную строку получить так:

```bash
openssl rand -hex 24
```

Образец со всеми названиями — в `bot/.env.example`. Локально можете скопировать его в `bot/.env`;
в git этот файл не попадёт, он в `.gitignore`. **На проде секреты хранятся в Cloudflare,
не в файлах** — так надёжнее.

### 5. Опубликовать обработчик

```bash
cd "/Users/nuralizhengisbay/Documents/Projects/Sam Naz Eng/bot" && wrangler deploy
```

В ответе будет адрес вида `https://samnaz-forms.ВАШ-АККАУНТ.workers.dev`.

### 6. Привязать webhook

Подставьте свои токен, адрес и секрет:

```bash
curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://samnaz-forms.<АККАУНТ>.workers.dev/tg/<WEBHOOK_SECRET>"
```

### 7. Указать адрес обработчика сайту

В файле `assets/js/config.js` впишите адрес с `/submit` на конце:

```js
window.SNZ.FORM_ENDPOINT = 'https://samnaz-forms.ВАШ-АККАУНТ.workers.dev/submit';
```

Пока строка пустая, формы просто показывают «Спасибо» и никуда не отправляют —
сайт из-за этого не ломается.

### 8. Указать домен

В `bot/wrangler.toml` поле `ALLOWED_ORIGIN` — домен сайта. С других адресов заявки не примутся.
На время тестов можно поставить `"*"`, потом обязательно вернуть домен.

## Как пользуется сотрудник

1. Открывает бота в Telegram, жмёт **/start**
2. Бот просит **логин** → вводит
3. Бот просит **пароль** → вводит
4. `✅ Доступ открыт` — заявки с сайта приходят в этот чат

Команды: `/status` — проверить подключение, `/stop` — отписаться.

Подписаться могут несколько человек — заявка придёт каждому. Кто не знает логин с паролем,
не подпишется, даже если найдёт бота.

## Защита

* **Токен не в браузере.** Лежит в секретах Cloudflare, в коде сайта его нет.
* **Вход по логину и паролю.** Просто найти бота недостаточно.
* **Скрытое поле-приманка.** Автоматические боты его заполняют и сразу отсеиваются.
* **Не чаще одной заявки в минуту с адреса.** От заваливания формы.
* **Приём только с вашего домена.**
* **Заявка не теряется.** Если никто ещё не подписан, она сохраняется в хранилище на 30 дней.
