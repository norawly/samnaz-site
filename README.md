# SAMNAZ ENGINEERING — сайт

Сайт ТОО «SAM-NAZ Инжиниринг»: инфраструктурное строительство и аренда
спецтехники в Казахстане с 2003 года.

Статический многостраничный сайт. Без сборки, без зависимостей, без CMS —
только HTML, CSS и обычный JavaScript. Папку можно положить на любой хостинг
как есть.

**Основной адрес:** <https://samnaz.group> · `samnaz.kz` перенаправляет туда же.

---

## Локальный запуск

```bash
python3 -m http.server 4173
```

Дальше <http://localhost:4173>.

Каталог техники подгружается через `fetch`, поэтому при открытии файла
двойным кликом (`file://`) он не отобразится — нужен локальный сервер.
Остальные страницы работают и без него.


Развёртывание и домены — **ХОСТИНГ.md**. Телеграм-бот — **ТЕЛЕГРАМ-БОТ.md**.

## Каталог техники

28 машин на прозрачных PNG, переведённых в WebP. **Кадр не обрезается**:
сохраняется исходное соотношение 3600×2160 (5:3), поэтому масштаб машин
сопоставим между собой и вёрстка не растягивается под длинные машины.

* `assets/img/equipment/` — 900×540, для сетки
* `assets/img/equipment/lg/` — 1600×960, для карточки

Поле под машиной белое; при наведении фон уходит в фирменное золото
с затемнением к краям, машина подрастает. Карточка открывает машину крупно
слева, характеристики справа; закрывается кликом по фону, крестиком или Esc,
листается стрелками.

Чтобы заменить фотографию — положите файл с тем же именем в обе папки.
Имя файла = поле `slug` в `assets/data/equipment.json`.

## Заявки в Telegram

Формы отправляют заявки в бот **@SamNazContact_Bot**. Ключ и список
получателей — `assets/js/vendor/metrics.js`, добавить получателя —
`bash bot/chat-id.sh`.

Ключ лежит в файле сайта и виден посетителям — осознанный выбор ради того,
чтобы обойтись без сервера. Что это значит и как перейти на безопасный
вариант (код готов, папка `bot/`) — в **ТЕЛЕГРАМ-БОТ.md**.

## Телефонная версия

Меню убрано в бургер, там же кнопка действия. Плитки направлений, цифр,
техники и команды — по две в ряд. Проекты — горизонтальная лента
с прокруткой. Карточка техники раскрывается текстом прямо в сетке,
без полноэкранного окна.

## Что осталось заполнить

### Главные люди компании
Четыре заглушки «Имя Фамилия». Нужны ФИО, должности и фотографии.
`index.html` и `about.html`, поиск по слову `ЗАМЕНИТЕ`.

### Фотографии
Часть снимков — стоковые, временные. Заменяйте файлы, **сохраняя имена**,
код трогать не нужно. Полноэкранные — от 2400 px по ширине,
проекты — 1800×1200.

| Файл | Где используется |
|---|---|
| `img/hero-poster.jpg` + `video/hero-loop.mp4` | первый экран главной |
| `img/hero-earth.jpg` | земляные работы |
| `img/hero-slab.jpg` | монолит, блок «Заявка» |
| `img/hero-cranes.jpg` | фон блока с цифрами |
| `img/srv-roads.jpg` `srv-bridges.jpg` `srv-water.jpg` `srv-rent.jpg` `srv-mono.jpg` | услуги |
| `img/about-blueprint.jpg` | блок «Кто мы», фон формы |
| `img/about-team.jpg` | шапка «О компании» |
| `img/city-night.jpg` | шапка «Контакты» |
| `img/projects/p1…p8.jpg` | 8 проектов в мозаике |

### Фотографии техники
Снимки настоящие, из старой базы, но низкого разрешения (17–80 КБ
в оригинале) — стоит переснять. На нескольких есть чужие водяные знаки
(`Doosan DX190WA`, `DX140W`).

### Характеристики техники
В старой базе часть данных повреждена — у `428F2 Caterpillar` вес указан
«42 т» вместо 4,2 т. На сайт выводится только то, что извлекается надёжно.
У 5 позиций из 28 характеристик нет вовсе: Doosan DX190WA, LiuGong 856,
CS78B Caterpillar, CAT 74 B, CAT 432 F2. Правится
в `assets/data/equipment.json`.

### Реквизиты
БИН, банковские реквизиты и часы работы для блока реквизитов
на странице контактов.

## Технические заметки

* Адаптив: 1440 / 1240 / 980 / 680 px.
* Шрифты локальные — сайт не обращается ни к одному внешнему домену,
  кроме карты на странице контактов и Telegram при отправке заявки.
* Все анимации отключаются при системной настройке «уменьшить движение».
* Заставка при входе показывается один раз за сессию, есть кнопка пропуска.
* При правке CSS или JS поднимайте номер в `?v=` у ссылок в HTML —
  иначе у посетителей останется старая версия из кэша. Сейчас `v=23`.
